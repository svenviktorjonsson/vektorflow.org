Performance

Two different questions use two separate tables.

All five 0.4.5 benchmark suites

The complete current evidence is public rather than hidden in workflow artifacts:

  1. Core language: VKF, C++, Rust and Zig
  2. Browser WebAssembly: native VKF, Chrome, Firefox and Safari
  3. Linear algebra: seven kernels against Eigen, faer and SciPy
  4. Symbolic mathematics: four kernels against SymEngine, SymPy and Symbolics.jl
  5. Optimizer policy: all five tested function landscapes

Each page contains the measured values and links to its machine-readable receipt.

Native language comparison

Programming-language comparisons use native machine-code artifacts on the same Linux x64 runner. Each ratio is VKF time divided by the competitor time, so a value below 1× means VKF was faster. The release selector shows only evidence measured for that exact VKF version.
