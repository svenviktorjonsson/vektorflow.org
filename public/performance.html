Version 0.4.7

Performance

Vektor Flow 0.4.7 publishes local, same-host measurements rather than a cross-platform ranking. Times are raw-kernel mean ± sample SD in milliseconds. Each ratio is VKF time divided by the named peer, so below 1× is faster.

Every populated cell uses 10 warmups followed by 100 measured runs. An em dash (—) means that exact release, workload, platform, browser, or comparison was not measured. It is not a zero and it does not inherit a result from an older release.

Browser WebAssembly versus native

Firefox runs version-matched VKF, C++, Rust, and Zig WebAssembly on the same Windows x64 host. The browser values are batched warm kernel means per operation. The VKF source is also timed as a raw native kernel on that host, so the final column compares Firefox WASM with native VKF. Chrome and Safari were not run for this release.
