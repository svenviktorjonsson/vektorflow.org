Vektor Flow

Vektor Flow (VKF) is an experimental compiled language for calculations, data and visuals. Typed values flow through scopes; the compiler resolves their types, shapes, storage and execution.

In brief

  • Language — Rust/ML-like value blocks with inferred shapes and Julia/NumPy-like vector flow.
  • Compiler — typed IR becomes direct native or WebAssembly output, not a wrapper around another compiler.
  • Execution — deterministic semantics with proven dataflow, SIMD, demand and parallel plans.
  • Targets — Windows, Linux, macOS and a sandboxed browser compiler.
