Vektor Flow 0.4.3

Ordinary VKF tests

Test files are ordinary VKF source files. vkf -t discovers top-level functions containing assertions. Required parameters receive values from zero-argument fixtures with the same name; vector fixtures use ordinary VKF lifting. Missing fixtures and removed test declarations produce exact diagnostics.

Native and browser compiler

Native and browser test discovery share the same compiler implementation and generated entry source. Browser execution remains client-side WebAssembly and keeps host process, network, filesystem, and DOM access outside user programs.

Windows PE artifacts preserve 32-byte generated-code alignment required by embedded AVX kernels. This prevents aligned literal loads in native SVD and related kernels from faulting when a larger output wrapper precedes the program. Native benchmark failures also retain the process status and hexadecimal Windows exception code instead of emitting an empty diagnostic.

VKF remains an unsupported experimental language with unstable APIs and syntax.

Packages

The release publishes preserved, versioned packages for Windows x64, Linux x64, macOS Apple Silicon, and browser WebAssembly. Publishing is additive: 0.4.0 downloads remain unchanged, and the release workflow refuses to overwrite an existing GitHub release.

Release evidence

As a patch release, 0.4.3 records 10-sample native and browser measurements without a speed threshold. The full native test suites, native/WASM parity, exact example output, browser execution, package closure, and publication gates remain mandatory. Future x.y.0 releases use 1,000 measured runs and enforce their performance thresholds.
